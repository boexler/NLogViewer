# Sentinel.NLogViewer

WPF controls and themes to visualize NLog log output in desktop applications.

- **Sentinel.NLogViewer** — core viewer control (targets `net8-windows`).
- **Sentinel.NLogViewer.MaterialDesign** — Material Design styling on top of the core library.

Repository: [https://github.com/boexler/NLogViewer](https://github.com/boexler/NLogViewer)
